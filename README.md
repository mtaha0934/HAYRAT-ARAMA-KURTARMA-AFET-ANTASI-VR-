# Afet Çantanı Hazırla (WebXR / Meta Quest)

Çocuklara (12+) afet ve acil durum çantasını öğreten, tarayıcıda çalışan eğitici VR oyunu.
Meta Quest Tarayıcı'da açıp "VR gözlükte oyna" düğmesine basın. Masaüstünde klavye/fare ile de oynanır.

Kumandalar: sol çubuk yürü · sağ çubuk dön · tetik çantaya at · yan tuş tut/fırlat · B/Y çanta.
